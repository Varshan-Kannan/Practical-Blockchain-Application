About this repository

This repository has my work from the practical sessions. Across them I deployed and used Solidity contracts from TypeScript, built a wallet-connected web page, made blockchain APIs in Python, listened for contract events, worked with decentralised storage, learned how wallet keys and signatures work, and built a custodial transaction service and an oracle service.

The code is kept as it was in my session folders. Private keys, .env files and other credentials are not included on purpose.

Technologies

Solidity, Ethereum Sepolia, ethers.js, TypeScript, Next.js, React, Python, FastAPI, web3.py, eth-account, IPFS (Pinata), MetaMask and EIP-1559 transactions.
